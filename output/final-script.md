# 最终脚本

## 标题
打工人的一天，靠轻醒把补给安排好

## 开头钩子
每次运动完或者下午忙到一半，我都很想找点吃的。最近我会把轻醒酸奶放进包里，想吃的时候就顺手拿出来。

## 口播文案
0:00-0:07  
Hello 大家，假期结束以后又回到打工节奏，早上赶时间、午休想动一动、下午又容易想吃点东西。

0:07-0:15  
所以我最近会给自己准备一盒轻醒希腊酸奶。原味我喜欢放早餐里，配燕麦和水果，开盖就能吃。

0:15-0:24  
它是 0 蔗糖、高蛋白的配方，口感比较厚实。对我来说，早上这样搭一下，会比随便买个甜点更顺手。

0:24-0:34  
中午约朋友打球，换上运动服出门。活动完先休息一下，喝点水，再拿出蓝莓味轻醒。

0:34-0:45  
蓝莓味很适合运动后这种时刻，酸甜感比较清爽，舀起来能看到绵密的质地，吃起来不像很重的甜品。

0:45-0:56  
如果下午在工位上有点饿，我会换黄桃味。它更像一个小小的下午茶，放在电脑旁边，边忙边吃两口。

0:56-1:08  
我喜欢它的点不是“多神奇”，而是能放进真实的一天里：早餐、运动后、下午茶，每个场景都不突兀。

1:08-1:15  
如果你也想给日常准备一个不折腾的轻食补给，可以从自己最常饿的那个时段试试看。

## 产品植入点
1. 早餐场景：原味轻醒搭配燕麦和水果，露出开盖、舀取和质地。
2. 产品信息：自然带出 0 蔗糖、高蛋白、希腊酸奶。
3. 运动后场景：蓝莓味作为运动后休息片段里的轻食补给。
4. 下午茶场景：黄桃味放在工位，承接上班族下午想吃点东西的需求。
5. 三口味分工：原味早餐、蓝莓运动后、黄桃下午茶。

## 结尾 CTA
评论区告诉我，你最想把轻醒放在哪个时段：早餐、运动后，还是下午茶？

## 合规风险提醒
- 不说“降糖”“控糖效果”“血糖稳定”等医学或功效表达。
- 不说“吃了就瘦”“减脂神器”“不长胖”等减肥承诺。
- 不使用确定性效果或营养机理表达。
- 不制造饮食负罪感，只表达个人场景、口感和搭配习惯。

# 视频链接分析能力规划

目标效果参考：输入小红书视频链接后，生成结构化视频拆解报告。

## 结果模块
1. 封面 & 标题分析
   - 封面视觉重点
   - 标题钩子
   - 是否适合商业植入

2. 选题分析
   - 内容主题
   - 目标人群
   - 情绪切入点
   - 和品牌 brief 的匹配度

3. 选品分析
   - 产品出现方式
   - 卖点承接方式
   - 使用场景
   - 合规风险

4. 文案分析
   - 开头钩子
   - 口播结构
   - 种草表达
   - CTA

5. 分镜拆解
   - 镜头图片
   - 画面内容
   - 口播/字幕
   - 道具/场景
   - 时长建议

## 后续真实分析链路
要从“小红书链接”真实生成这些结果，需要增加后端能力：

1. 链接解析
   - 接收小红书链接
   - 获取标题、作者、封面、视频地址或截图

2. 视频抽帧
   - 每 2-4 秒抽一帧
   - 保存关键帧到 `references/frames`
   - 当前已提供 `scripts/video_pipeline.py`

3. 视觉识别
   - 识别封面、人物、产品、场景、字幕
   - 提取每个镜头的画面信息
   - 当前已提供 `scripts/select_frames_ai.py`，支持启发式选帧和 AI 视觉选帧

4. 文案生成
   - 结合 brief 和视频结构
   - 输出封面、选题、选品、文案、分镜拆解

5. 飞书写入
   - 把分析报告和图片写入飞书文档

## 注意
小红书链接解析可能受登录、反爬、权限和平台规则限制。
如果无法直接抓取，可以采用人工上传截图/视频文件的方式完成同样流程。

## 命令行接入
安装 videodl：

```bash
pip install videofetch
```

下载并抽帧：

```bash
python scripts/video_pipeline.py --url "你有权分析的小红书视频链接"
```

或使用本地视频：

```bash
python scripts/video_pipeline.py --video "C:\path\to\video.mp4"
```

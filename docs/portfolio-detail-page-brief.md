## 三、项目背景

MCN 商单交付通常需要人工完成 Brief 拆解、达人筛选、参考内容分析、脚本撰写、分镜设计、合规检查和文档交付。这个流程重复性高，但又不能简单依赖大模型直接生成文案，因为商单内容需要兼顾品牌卖点、达人风格、平台语境和合规风险。

本项目尝试把这条内容生产链路拆成多个可执行步骤，通过 AI Agent 工作流将「理解需求 → 参考分析 → 内容生成 → 风险检查 → 文档交付」串联起来，让商单脚本生产从一次性生成变成可复用、可检查、可交付的自动化流程。

页面文案：

> 工作流从品牌 Brief 开始，先识别产品卖点、目标人群、平台语境和风险禁区，再筛选适合的达人样本，抽象可迁移的标题公式、开头钩子、镜头节奏和表达方式，随后生成 60-90 秒小红书短视频脚本与分镜，最后进行合规质检并写入飞书文档。

流程步骤：

1. Brief 解析：提取产品卖点、目标人群、平台调性和风险禁区。
2. 达人匹配：按人设、内容场景、表达方式和品牌匹配度筛选达人。
3. 风格拆解：只迁移标题公式、开头钩子、镜头节奏、语气和场景结构，不复制原句。
4. 脚本分镜生成：输出标题、口播、产品植入点、CTA 和 6 个以上镜头。
5. 合规质检：检查减肥、治疗、降糖、绝对化宣传、照搬达人内容等风险。
6. 飞书写入：把最终交付稿通过脚本写入飞书文档。

## 六、核心功能模块

### 1. Brief 智能解析

系统会从品牌 Brief 中提取品牌、产品、卖点、人群、平台和表达禁区，避免脚本生成时偏离商业目标。

### 2. 达人筛选与内容参考

根据人设、内容场景、表达方式和品牌匹配度筛选小红书达人。本次项目中筛选了 3 位候选达人，并明确主达人、副达人和备选达人。

### 3. 脚本与分镜生成

系统会生成完整的 60-90 秒短视频脚本，包括标题、开头钩子、口播文案、产品植入点和结尾 CTA。同时输出可直接用于拍摄的分镜表。

### 4. 合规风险质检

系统会检查脚本中是否存在减肥、治疗、降糖、绝对化表达、夸大前后对比或照搬达人内容等风险，并给出保留表达和禁用表达。

### 5. 飞书文档自动写入

通过飞书 Open API 自动创建文档并写入 Markdown 结构化内容，让最终交付物可以直接进入团队协作文档。
